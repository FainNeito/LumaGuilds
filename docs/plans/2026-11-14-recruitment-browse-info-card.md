# Recruitment browse card and guild info card

Goal: build the approved mockup (artifact "Recruitment and Guild Info") from TEST feedback (REQ-236, REQ-237).

## Recruitment

- "More listing options" hid Browse, My Applications, setup and settings. Players missed it.
- Dialog buttons use a fixed two-column grid, so a full-width button cannot sit mid-grid. The browse action is a clickable card with the same framed art as the status card, placed directly under it, with gold text.
- Setup, settings and My Applications become ordinary buttons.

## Guild info card

- Order: name, prestige badge and tier with level, details, yes/no facts, then "Active wars" last.
- The badge uses the guild's Nexo prestige glyph (the same one as the tab list).
